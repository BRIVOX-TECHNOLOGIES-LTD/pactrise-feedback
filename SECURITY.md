# Security policy

Security reports must **not** be submitted as public GitHub issues.

If you believe you have discovered a vulnerability affecting Pactrise, please use GitHub's **Report a vulnerability** private reporting option on the repository's Security tab **if enabled**, or contact Pactrise privately through https://pactrise.net and request a secure reporting channel.

## Include in a private report

- A concise description of the issue and potential impact
- Affected feature or endpoint, without publishing sensitive URLs
- Safe reproduction steps and sanitized evidence
- Your preferred contact method

## Responsible disclosure

Do not access other users' data, extract personal information, perform destructive testing, disrupt services, or publicly disclose exploit details. We ask researchers to give the team a reasonable opportunity to investigate and address validated issues.

This public feedback repository does not contain the production application code. No bug bounty or safe-harbor commitment is implied by this document.
